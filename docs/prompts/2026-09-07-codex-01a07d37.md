### Replied · 2026-09-07 14:53

````text
Skills are invoked in **two ways**:

- **Explicitly:** Name the skill in your message, such as `$openai-docs explain Codex configuration` or “Use the openai-docs skill.” In the Codex CLI and IDE extension, you can also type `$` or use `/skills` to select one.
- **Automatically:** Codex matches your request against installed skill descriptions and selects a relevant skill. That’s how I selected `openai-docs` for this question. [Official documentation](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills)

Once selected, Codex reads the skill’s **`SKILL.md`** and follows its workflow, using any referenced scripts, resources, or tools as needed. Initially, only the skill’s name, description, and path are loaded. [How skills are loaded](https://learn.chatgpt.com/docs/build-skills)

For your repo, an explicit example would be:

```text
$clean-local-do wipe the local Durable Object state
```

That particular skill requires an explicit reset request under your repo’s rules.
````
