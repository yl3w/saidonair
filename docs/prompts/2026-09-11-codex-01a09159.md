````text
### 1. Validate, but do not modify, the channel

The system can read the channel to confirm:

No channel field changes.

### 2. Create an episode attempt

  reason = owner_retry

```

Nothing is inserted into:

```text
ingestion_runs
ingestion_run_episodes
```

### 3. Handle the episode based on its current state

For an already available episode:

```text
episodes                 unchanged while retry runs
episode_summaries        unchanged while retry runs
summary_reads            unchanged

Readers continue seeing the current summary.

```text
episodes.status          → pending
attempt_count            → 0
failure/wait/skip fields → cleared
```

These are episode changes, not channel changes.

The Workflow processes only the supplied `videoId`:

→ chunk
→ embed
→ summarize

It does not fetch the channel RSS feed or discover siblings.

episode_summaries             replace summary
episodes.chunk_count          update
episodes.vectorized_at        update
episodes.processed_at         unchanged
summary_reads                 unchanged
episode_ingestion_attempts    → completed

episodes.processed_at         → now
episode_summaries             insert
episode_ingestion_attempts    → completed
```

```text
episodes                      unchanged
episode_summaries             unchanged
episode_ingestion_attempts    → failed
```

| `channels` | No change |

| `ingestion_run_episodes` | No change |
| `episodes` | Changed only when replacement succeeds |
| `episode_summaries` | Replaced only on success |
| `summary_reads` | No change |

| New `episode_ingestion_attempts` | Inserted and updated |
````
